# 📌 Overview

The **LeetCode Problem of the Day Solutions** repository is a comprehensive collection of **daily LeetCode challenge solutions** solved consistently to strengthen **Data Structures and Algorithms (DSA)** skills and enhance **technical interview preparation**.

This repository serves as a structured resource for students, software engineers, and coding enthusiasts who wish to follow a disciplined problem-solving routine. Every solution is carefully written with an emphasis on **clean code**, **optimized approaches**, and **clear understanding of algorithms**.

The repository includes solutions from various difficulty levels ranging from **Easy**, **Medium**, to **Hard**, covering a wide spectrum of topics such as:

- Arrays
- Strings
- Linked Lists
- Trees & Binary Trees
- Binary Search
- Dynamic Programming
- Graphs
- Greedy Algorithms
- Backtracking
- Sliding Window
- Stack & Queue
- Heap / Priority Queue
- Trie
- Union Find (DSU)
- Bit Manipulation
- Math
- Recursion
- Hashing
- Prefix Sum
- Segment Tree
- And many more...

Each solution aims to provide:

- ✅ Optimized Code
- ✅ Clean Implementation
- ✅ Interview-Friendly Logic
- ✅ Well-Structured Repository
- ✅ Daily Consistency
